Mega Man 3 NES ROM Text Editor<br/>
Programmed by: Shawn M. Crawford [sleepy] 03/27/2016 in C#<br/>
---------------------------------------------------------<br/>

Features:<br/>
	* Edit text in the game <br/>
	* Works with the USA ROM<br/>

Usage:
	*Open the Rom, change text, click the Update Text button, make sure you have a backup in case something breaks.<br/>
